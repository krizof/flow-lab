Flow Lab 1.2.0 — 31.10.2026

УСТАНОВКА
1. В старой Flow Lab выберите в трее «Выйти полностью».
2. Запустите Flow-Lab-Setup.exe. По умолчанию программа устанавливается
   в %LOCALAPPDATA%\Programs\FlowLab, появляется в меню «Пуск» и списке
   установленных приложений Windows. Python не требуется.
3. Откройте Flow Lab из меню «Пуск». Подтвердите права администратора:
   они нужны для перехвата пакетов zapret и восстановления голоса.
4. Старые настройки из %LOCALAPPDATA%\DiscordFlowLab читаются автоматически.
   Сохраняйте выбранную папку zapret: она может быть вашей внешней папкой.
   Уже включённый автозапуск переносится при первом открытии установленной версии.
5. Следующие обновления: Настройки → Проверить сейчас → Обновить и перезапустить.
   Кнопка проверяет GitHub сразу. Шесть часов — только интервал фоновой проверки.
   Переносной Flow-Lab.exe также остаётся доступен; он обновляется в своей папке.

РАБОЧАЯ НАСТРОЙКА ВЛАДА
Подключения → Выбрать VLAD STABLE → Запустить.
Сначала выберите ту полную папку zapret, с которой всё заработало.
Кнопка добавляет BAT без замены его ACTIVE-файлов и списков.
Для новой установки zapret встроенный вариант добавляется вместе с 1.10.4.
Восстановление голоса — отдельная настройка. Выбор BAT её не включает.
Сетевые правила совпадают с T4; не меняйте подменный пакет без необходимости.
При проверке Влада использовался автоматический регион комнаты, а автор
демонстрации перезапустил её. Это не гарантия для любого другого подключения.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
1. Сети и подбор → Проверить соединение. Сеть не переключается.
2. Откройте «Результат проверки». Журналы берутся с этого ПК, свежесть указана.
3. Выберите проблему: Discord, чат Twitch или оба.
4. Для подбора вручную остановите функции, закройте Discord/игры и внешний zapret.
   Если звонок открыт в браузере, завершите его тоже. Отключите VPN для проверки
   именно пути без VPN. Программа не закрывает приложения и VPN за вас.
5. Подтвердите, что временная проверка допустима, нажмите «Подобрать настройки».
   До четырёх вариантов, максимум 4 минуты. Проверяются временные копии.
6. Если найдено повторяемое улучшение, нажмите «Применить проверенный вариант»,
   затем «Запустить». «Отменить последнее применение» возвращает старую копию.
7. Проверьте голос и обе демонстрации, чат Twitch в вашем браузере. Если всё хорошо,
   сохраните рабочие настройки и профиль сети. Для переноса используйте
   «Скачать мои настройки в ZIP» — распаковывать нужно весь архив.

ЧТО МОЖЕТ ПРОВЕРКА
API Discord, передачу до 512 КБ файла интерфейса, Hello от Gateway, открытие
WebSocket чата Twitch, HTTPS YouTube и контрольный адрес. Каждый этап дважды.
Подбор меняет только целевые TCP-профили Discord/чата Twitch. Исходные профили
UDP остаются прежними. Переходов на случайные TTL или изменения игр нет.
Проверка не подтверждает слышимость голоса, доставку сообщений, воспроизведение
видео или отсутствие редких сбоев. Настройки не применяются скрытно.
Остановка по сроку означает «результат не подтверждён», а не «починено».

ДОПОЛНИТЕЛЬНЫЕ НАСТРОЙКИ
Настройки → Дополнительные параметры zapret: файл Fake для Discord UDP и откат.
Сайты и адреса: домены, исключения, обновление IPSet.
Игровой режим и FACEIT в версии 1.2.0 не изменялись.

УДАЛЕНИЕ
Выйдите через трей, затем удалите Flow Lab через настройки приложений Windows.
Автозапуск этой установленной копии удаляется. Настройки, журналы и пакеты zapret
сохраняются в %LOCALAPPDATA%\DiscordFlowLab. Внешняя папка zapret не удаляется.
Если Windows не даст удалить задачу автозапуска, установщик попросит сначала
отключить её в настройках Flow Lab; чужие задачи он не удаляет.
