FLOW LAB — БЫСТРЫЙ ЗАПУСК

Откройте Flow-Lab.exe и подтвердите UAC.
Установите zapret из интерфейса, выберите рабочую стратегию, нажмите «Запустить».
Настройки позволяют отдельно включить Telegram и экспериментальное восстановление
голоса Discord. Для Telegram подтвердите подключение кнопкой «Подключить Telegram».
FACEIT EU переключается одной кнопкой; прежние настройки сохраняются для отмены.
Сворачивание/крестик — в трей. «Выйти» — полное завершение.

Обновления: «Настройки» → «Обновления Flow Lab» → «Обновить и перезапустить».
Проверка автоматическая, установка по кнопке. Работавшие функции после обновления
запускаются снова. При отказе новой версии предусмотрена попытка возврата старого EXE.

Если осталась версия 0.6 или старше — один раз скачайте свежий EXE вручную.
Требования: Windows 10/11 x64, .NET Framework 4.8. Python пользователю не нужен.
Документация и загрузки: https://github.com/krizof/flow-lab

Логи никуда автоматически не отправляются. Публикуемые вами отчёты могут содержать
IP и пути. Работа игровых серверов зависит от сети; обещаний полной совместимости нет.
