FLOW LAB 0.9 — БЫСТРЫЙ ЗАПУСК

1. Откройте Flow-Lab.exe и подтвердите UAC.
2. Установите zapret из интерфейса или выберите его папку в настройках.
3. В карточке «1. Стратегия zapret» выберите рабочую стратегию.
   «Выбрать стратегию TTL4» — только быстрый выбор варианта zapret.
4. Если нужно восстановление голоса Discord, отдельно проверьте переключатель
   в карточке «2. Восстановление голоса Discord» на главной.
   TTL4 и восстановление — независимые настройки. Восстановление экспериментальное.
5. Нажмите «Запустить».

Telegram включается отдельно в настройках. На главной нажмите «Подключить Telegram»
и подтвердите использование локального прокси в Telegram.
FACEIT EU переключается одной кнопкой; прежние настройки сохраняются для отмены.
Сворачивание/крестик — в трей. «Выйти» — полное завершение.

«Сайты и адреса»: официальный IPSet, свои сайты и исключения, отмена последней записи.
Сначала выключите FACEIT и остановите функции, после сохранения запустите снова.
Добавленный сайт обрабатывается профилями выбранной стратегии, использующими список.
«Диагностика» → «Проверить файлы выбранной стратегии» — проверка файлов, не сети.

Обновления: «Настройки» → «Проверить Flow Lab» → «Обновить и перезапустить».
Проверка автоматическая, установка по кнопке. Работавшие функции после обновления
запускаются снова. При отказе новой версии предусмотрена попытка возврата старого EXE.
Если осталась версия 0.6 или старше — один раз скачайте свежий EXE вручную.

АВТОЗАПУСК WINDOWS (0.9)
«Настройки» → «Автозапуск Windows» → «Запускать Flow Lab при входе в Windows».
«Сразу запускать выбранные функции» включает сохранённый набор zapret,
восстановления и Telegram. Без неё программа только открывается в трее.
Нажмите «Применить автозапуск». Сохранение сразу проверяется через Windows.
Запуск запланирован через 15 секунд после входа текущего пользователя.
Создаётся задание Планировщика с правами администратора и InteractiveToken;
пароль не запрашивается и не сохраняется. При выходе из учётной записи
программа завершается. На батарее запуск разрешён; ограничение 72 часа снято.
При ошибке старта функций окно остаётся открытым с сообщением.
Для отключения снимите галочку и нажмите «Применить автозапуск».
Задание называется FlowLab-<SID пользователя>; чужие задания не изменяются.

ВАЖНО: сначала переместите EXE в постоянную локальную папку и запустите оттуда.
После ручного переноса нажмите «Применить автозапуск» ещё раз. Кнопка
«Проверить состояние» показывает, если задание ссылается на другой путь.
Обновление через приложение заменяет EXE на прежнем месте, путь сохраняется.
Пункт по умолчанию выключен. Установка новой версии не включает его сама.

Windows 10/11 x64, .NET Framework 4.8. Python пользователю не нужен.
Документация и загрузки: https://github.com/krizof/flow-lab
Логи автоматически никуда не отправляются. Отчёты могут содержать IP и пути.
