# Flow Lab

Приложение для Windows: управление zapret, Telegram-прокси и экспериментальное восстановление голоса Discord.

**[Скачать Flow-Lab.exe](https://github.com/krizof/flow-lab/releases/latest/download/Flow-Lab.exe)** · **[Последний выпуск](https://github.com/krizof/flow-lab/releases/latest)**

Для использования достаточно EXE. Python не нужен. Windows 10/11 x64, .NET Framework 4.8.

## Возможности

- Установка и обновление zapret из официальных релизов Flowseal; выбор полной стратегии.
- Режим FACEIT EU: Game Filter UDP + IPSet any, автоматический перезапуск своего zapret, возврат прежних параметров.
- Встроенное ядро tg-ws-proxy, без второго интерфейса. Подключение Telegram подтверждается отдельно в Telegram.
- Экспериментальное восстановление IPv4 UDP-потоков Discord при пропадании ответов.
- Обновление официального IPSet, редактор своих сайтов и исключений с проверкой ввода и отменой последней записи.
- Работа в трее, проверка файлов стратегии, диагностика и экспорт отчёта по кнопке.
- Начиная с 0.7 — обновления самого Flow Lab, отметка важных выпусков и описание изменений.

## Первый запуск

1. Откройте EXE и подтвердите запрос администратора.
2. В блоке zapret проверьте обновление и установите пакет или выберите существующую полную папку в настройках.
3. Выберите рабочую для вашей сети стратегию. TTL4 — экспериментальный вариант, не универсальная настройка.
4. Отдельно настройте карточку **«2. Восстановление голоса Discord»** на главной. Кнопка **«Выбрать стратегию TTL4»** меняет только стратегию и не переключает восстановление.
5. Нажмите «Запустить». Режим FACEIT можно переключать без ручного перезапуска.
6. Сворачивание и крестик отправляют программу в трей. Полное завершение — «Выйти».

Если zapret уже запущен отдельной службой/батником, Flow Lab не завершает его. Для автоматического переключения режима сначала остановите внешний экземпляр и запускайте zapret через Flow Lab.

## Свои сайты и исключения

На вкладке **«Сайты и адреса»** можно обновить официальный IPSet Flowseal, добавить сайты для обработки или исключения по доменам/IP/CIDR. URL преобразуются в домены, дубли удаляются; ошибки показываются до записи. «Вернуть последнее изменение» отменяет последнюю запись списка или IPSet.

Для изменения выключите FACEIT и остановите функции, затем сохраните список и нажмите «Запустить». Режимы IPSet any/none при обновлении сохраняются. Списки действуют только в профилях выбранной стратегии, которые на них ссылаются. Черновики в редакторе сохраняются при переключении списков до закрытия приложения.

Источники интеграции: [service.bat Flowseal](https://github.com/Flowseal/zapret-discord-youtube/blob/main/service.bat), [официальный IPSet](https://github.com/Flowseal/zapret-discord-youtube/blob/main/.service/ipset-service.txt).

## Обновления

При открытии и каждые 6 часов приложение проверяет опубликованный стабильный GitHub Release. Новая версия отмечается в окне и трее. Проверку можно отключить в настройках.

«Настройки» → «Обновления Flow Lab» → **«Обновить и перезапустить»**. Автоматической установки без нажатия нет. Во время замены EXE управляемые функции ненадолго останавливаются; настройки сохраняются. Если интерфейс новой версии не подтвердит запуск, помощник пытается восстановить старый EXE.

Версии 0.6 и старше нужно **один раз заменить вручную**: у них ещё нет этого механизма. Пользователям 0.7+ не нужны GitHub-аккаунт и личный токен.

## Ограничения

Состояние процесса не доказывает доступность сервера или слышимость голоса. Работа FACEIT/Discord зависит от сети и выбранной стратегии. IPSet any может мешать другим сайтам; после игры режим можно выключить. Приложение не меняет регион аккаунта FACEIT или параметры античита.

GitHub HTTPS, ожидаемый адрес и SHA256 используются для проверки загрузки. Это не цифровая подпись Authenticode; EXE пока не подписан сертификатом издателя.

Логи автоматически никуда не отправляются. Экспортированный отчёт может содержать IP-адреса и локальные пути — проверяйте его перед публикацией.
